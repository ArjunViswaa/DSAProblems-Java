# DSA Problems in Java

Daily DSA practice in Java, Sep 2026 to Mar 2027. Problems follow the TUF+ A2Z sheet, grouped by pattern.

## Structure

```
src/main/java/<pattern>/<ProblemName>.java   one problem per file, with a main() that runs its test cases
src/test/java/                               JUnit tests (added from Week 4)
```

## Rules

- Solved without AI. Reviewed only after a working submission.
- Every file notes time and space complexity and the time taken.
